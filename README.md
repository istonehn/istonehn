# Hola, soy Istonehn 👋

Trabajo en **Qeubo**, un marketplace pensado para Venezuela. Me interesa construir productos útiles, cuidar la experiencia de quienes los usan y llevar las ideas desde el prototipo hasta una aplicación que funcione de verdad.

### En qué estoy trabajando

- **Qeubo web:** frontend en JavaScript conectado a un backend en PHP y MySQL.
- **Qeubo móvil:** adaptación de la experiencia web para Android e iOS con Capacitor.
- **Experiencia de producto:** publicaciones, búsqueda por ubicación, fotografías, mensajería y herramientas para compradores y vendedores.

Prefiero avanzar con cambios pequeños, probar lo que construyo y mantener una base de código comprensible. Este perfil irá creciendo junto con los proyectos que pueda compartir públicamente.
